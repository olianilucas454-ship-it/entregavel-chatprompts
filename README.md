# 🚀 Pack de Comandos Secretos para ChatGPT

Repositório da Landing Page de Vendas e dos Entregáveis Digitais do produto **Pack de Comandos Secretos para ChatGPT**.

## 📁 Conteúdo do Repositório

- `index.html`: Página de Vendas (Landing Page) otimizada para CRO e Meta Ads.
- `dashboard.html`: Aplicativo Web Interativo para buscar, filtrar por categorias e copiar prompts em 1 clique.
- `ebook.md`: E-Book completo em Markdown com 40+ comandos e guia de Engenharia de Prompts.
- `images/`: Imagens e criativos visuais de alta conversão.

## 🌐 Publicação no GitHub Pages

Para publicar este site gratuitamente no **GitHub Pages**:

1. Crie um repositório no seu GitHub chamado `pack-prompts-chatgpt`.
2. Faça o push dos arquivos deste projeto:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Sales page & deliverables"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/pack-prompts-chatgpt.git
   git push -u origin main
   ```
3. No GitHub, vá em **Settings > Pages**.
4. Em **Source**, selecione `Deploy from a branch`, escolha a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**. O seu site estará online em alguns segundos no link:  
   `https://SEU_USUARIO.github.io/pack-prompts-chatgpt/`
